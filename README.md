# Matepaper

Matepaper 是一款本地优先的 Windows 桌面个人工具箱，用于集中管理便签、备忘录、待办、日子记录、阅读记录和密码本。软件以本地数据存储为核心，不依赖云端账号，适合记录日常想法、任务安排、生活片段、阅读进度和常用账号信息。

## 功能特点

- **本地便签**：记录灵感、片段和 Markdown 内容，支持标签、收藏、置顶和归档。
- **备忘录**：记录临时事项，支持提醒时间和快捷提醒预设。
- **待办**：管理任务状态、截止日期和优先级。
- **日子记录**：按日期记录生活片段、心情和日常回顾。
- **阅读记录**：记录书籍作者、阅读状态、页码、进度、评分和摘记。
- **密码本**：记录账号、网址和备注，密码内容使用本地主密码加密保存。
- **快速捕获**：通过全局快捷键快速打开小窗口，不同类型会显示对应的专属表单。
- **Markdown 导入**：可导入本地 Markdown 文件生成便签。
- **活动热力图**：按 28 天、84 天或 168 天统计记录活跃情况。
- **外观设置**：支持浅色、深色、跟随系统、强调色、字号比例、背景图片、透明度、模糊、遮罩和暗角设置。
- **桌面体验**：支持托盘、窗口置顶、开机自启动、安装包和便携包发布。

## 数据与隐私

Matepaper 默认将数据保存在当前系统用户的数据目录中，采用本地 JSON 文件持久化。密码本中的密码字段会使用主密码派生密钥后进行 AES-GCM 加密，主密码不会被保存。

请注意：

- 本软件当前不提供云同步功能。
- 忘记密码本主密码后，已加密的密码无法恢复。
- 建议定期备份本地数据文件和重要记录。

## 下载与运行

前往发布页下载：

[Matepaper v0.1.0](https://github.com/2310770803/Matepaper/releases/tag/v0.1.0)

可选下载文件：

- `Matepaper-Setup-0.1.0-x64.exe`：安装版，适合普通用户安装使用。
- `Matepaper-Portable-0.1.0-x64.exe`：单文件便携版，下载后双击运行。
- `Matepaper-win-unpacked-0.1.0-x64.zip`：完整目录便携包，解压后运行 `Matepaper-win-unpacked/Matepaper.exe`。

如果使用目录便携包，请移动整个 `Matepaper-win-unpacked` 文件夹，不要只单独复制 `Matepaper.exe`。该程序依赖同目录下的 `resources`、DLL 和 Electron 运行时文件。

## 本地开发

环境要求：

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- npm

安装依赖：

```bash
npm ci
```

启动开发环境：

```bash
npm run dev
```

运行测试：

```bash
npm test
```

构建前端：

```bash
npm run build
```

生成 Windows 安装包和便携包：

```bash
npm run release:win
```

构建产物会输出到 `release/` 目录。

## 项目结构

```text
electron/      Electron 主进程、预加载脚本、本地存储和快捷键逻辑
src/           React 前端、领域模型、外观设置和测试
public/        应用图标资源
scripts/       Windows 打包、图标写入和发布辅助脚本
docs/          发布说明和维护文档
standalone/    独立 UI 原型页面
```
